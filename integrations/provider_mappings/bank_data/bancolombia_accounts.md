# Bancolombia Accounts And Transactions

## Clasificacion

- categoria primaria: `bank_data`
- bounded context principal: `finance.accounts` + `finance.transactions`
- contrato canonico: `open_banking.normalized_payload`

## Nota

Este documento aplica solo a APIs de Bancolombia orientadas a cuentas,
balances o movimientos.

No aplica a pagos ni a tasas de mercado.
